## 判定基準（2026-08-19 時点）

resources[].last_modified のみで判定する。

判定に使わないもの:
- パッケージの metadata_modified
  ファイル更新以外（タイトル修正など）でも動くため
- リソースの metadata_modified
  目黒区で 2017-07 追加時に全 60 件が一斉更新された。
  無関係なファイルまで動くため使えない
- HTTP Last-Modified / ETag
  サーバー移行や再配置でも動き、中身が変わった根拠にならない
- size, datastore のレコード数
  記録はするが判定には使わない。
  必要になれば raw_json から遡って検証する
