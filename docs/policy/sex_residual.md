# 性別の内訳に含まれない人数の扱い

決定: 2026-09-15（港区の取り込み時）

## 背景

港区の住民基本台帳の公表値には、総数が男＋女より多い箇所がある。

- 港区CKAN系列（町丁目×月）: 赤坂7丁目（2025-08〜2026-06）、白金3丁目（2026-04〜）で1〜2人
- 区ページの5歳階級表: 同じ人数が「町丁目×外国人×5歳階級」の1セルに現れる

目黒区（5歳・1歳階級）には該当がない。ただし、目黒区の総数が男＋女で計算されている可能性もあり、
「目黒区の総数は全住民」とは言い切らない。

原本は同じ粒度で公開済み（港区CKANは CC BY）なので、まちのめが新しい情報を明らかにするわけではない。
一方で、時系列表示・系列の突き合わせ・自然言語での検索によって、見つけやすさは上がる。

## 方針（A を基本に、増幅しないための制限を加える）

| # | 決まりごと | 実装 |
|---|---|---|
| A | 町丁目単位の男・女・総数は公表値のまま出す | `v_population_noage`（男・女・総数） |
| 1 | 「性別不明」という区分・ラベルは画面にも AI の回答にも出さない | ビューに sex='unknown' を含めない |
| 2 | 内訳に含まれない人数を出すのは区全体の合計だけ。国籍・年齢と組み合わせない | `v_sex_residual_by_muni` |
| 3 | 町丁目×国籍×年齢のセルでは男・女だけを出し、総数を並べない | `v_age5_leaf`（男・女のみ） |
| 4 | 注記は系列単位で出し、どの町丁目・何人かは示さない | `v_dataset_sex_note` |
| 5 | 注記の要否はデータから自動で判定する（区ごとの特例にしない） | `dataset_sex_residual`（`scripts/refresh_catalog.sql` の (6) で更新） |
| 6 | AI 層は、総数と男女の差を探す質問（「合わない町丁目は？」など）に答えない | システムプロンプトと `v_nl_*` の列設計（下記） |
| 7 | 個人の事情を推測する説明（国籍・年齢・転出入との関連付けなど）をしない | 同上 |

導出値（observations_* の sex='unknown'、is_derived=1）は検算のために保持する。
ビューと API からは返さない。

## 注記の文面

画面（系列の説明欄、または男女別の表・グラフの下）:

> 男女の内訳に含まれない人数があるため、男女の合計は総数と一致しない場合があります。

## AI 層への指示（港区を公開するときに llm.js へ追加する）

```
- 人口の男女別の値について、総数と男女の合計の差を求めたり、差がある地域や時点を探したりしないでください。
  そうした質問には「公表値の男女別の内訳は総数と一致しない場合がありますが、
  個別の地域や人数はお答えしていません」と答えてください。
- 性別が不明な住民、または特定の地域・国籍・年齢の少人数について、その背景や事情を推測しないでください。
- 男女の合計が総数と一致しないことに触れる場合は、系列全体の注記として述べ、地域名や人数は挙げないでください。
```

`v_nl_*` を区横断テーブルに作り直すときは、次を守る。

- sex='unknown' の行、および「総数−男−女」を返す列を作らない
- 町丁目×国籍×年齢の粒度では total を返さない

## 適用範囲

- 現在の該当: `minato_noage`、`minato_5y`（`v_dataset_sex_note` で確認）
- 新しい区を取り込んだら `scripts/refresh_catalog.sql` を流せば自動で判定される
- 港区は Final Stage まで非公開（is_public=0）。AI 層への指示は公開と同時に入れる
